

## Folder Structure

- `assets/images/` - shared images used by practice pages and clones
- `html-css-practice/basics/` - standalone HTML/CSS topics like display, position, pseudo classes, animation, media query, etc.
- `html-css-practice/flexbox-grid/` - Flexbox and CSS Grid practice files
- `javascript-practice/basics/` - JavaScript syntax and logic practice
- `projects/clones/` - UI clone practice projects like Amazon, BookMyShow, Flipkart, and YouTube
- `projects/admin-dashboard/` - dashboard layout practice
- `projects/flipkart-flexbox/` - larger Flipkart clone using Flexbox
